# hongguo TV · 电视端原生客户端（0.22.2 分支）

**[⬇ 下载最新 APK](https://cnb.cool/lzyr9010/hongguoTV-updates/-/releases/latest)** · Android 8.0+ · Kotlin / Media3 · 单 APK，无需部署服务

本仓库是 hongguo TV 的**自用分支**：以 0.17.0 的电视端原生客户端为基线，重做界面并针对首页、搜索、播放体验做了一轮优化。仓库 `main` 分支为可构建源码，Release 页面提供对应安装包。

## 相较 0.17.0 做了哪些优化

### 播放

- **帧率自适应**：播放器进入 READY 后按视频轨道的实际帧率调用 `Surface.setFrameRate`，API 29 起用 `FIXED_SOURCE`、API 31 起用 `SEAMLESS`，减少 24/25/30fps 片源的抖动与重复帧
- **自动切集不再黑屏**：换集改为原地换源，不再 `stop()` 后重建，旧播放源延迟 1.5s 释放；无缝切集时关闭缓冲圈，起播缓冲由 1000/2000ms 收紧到 500/1000ms

### 首页

- **热门发现改为跨类型混合池**：短剧 + 漫剧一起抽，一次 12 部、两行各 6 个，可点「换一批」
- **不放回抽牌**：每批抽中的从牌堆移除，72 部以内零重复；牌堆将空才重洗，并避免下一批立刻重复
- **本地缓存瞬时渲染**：进首页先用上次的 12 部，不再等抓取；缓存 24 小时过期后自动发新一批
- **懒建池 + 后台串行抓取**：无缓存或已过期才建池（分别延后 400ms / 1500ms），用户主动点「换一批」时才并发抓取
- **封面修复**：封面高度每页只计算一次，按行分摊高度，第二行不再被裁切；对屏上可见卡片补发封面请求

### 搜索

- **合并检索**：短剧与漫剧各搜一页后交替合并展示，不再需要先选类型
- **搜索页头部固定**：搜索框与类型行留在顶部，只收起建议区，滚动时不再被顶走
- **首拼 + 手机输入**：遥控器按字母拼首拼（「霸道总裁」→ B D Z C），或用「手机输入」在手机上打字，电视同步搜索

### 界面与交互

- **文字大小 7 档**：76%~124%，步进 8%，设置里实时预览，全局生效
- **二级头部自动收起**：片库、排行榜、剧场、搜索页的标题区在列表滚动过首行时动画收起，tab 栏固定；回到顶部自动展开
- **弹窗统一样式**：新增独立弹窗面板背景，焦点框与卡片圆角、留白统一
- **精简首页尾部**：移除底部选中剧名块与冗余的「更多热门」入口，焦点链改按行计算

### 行为变化（需要注意）

- **移除应用内更新**：删除 `AppUpdater` 与相关接线，安装包只保留网络权限，不再申请「安装未知来源应用」。升级方式改为重新下载安装
- 版本号从 `0.17.x / versionCode 12` 递增到 `0.22.2 / versionCode 25`

## 如何使用

1. **下载安装**：从 [Release 页面](https://cnb.cool/lzyr9010/hongguoTV-updates/-/releases/latest) 下载 `hongguotv-0.22.2-debug.apk`，拷到电视或电视盒子安装；提示时允许「安装未知来源应用」
2. **首次启动**：联网即用，不需要填服务器地址，也不需要登录
3. **遥控器操作**：方向键移动焦点，OK 确认，返回键回上一级；顶部 tab 切换首页 / 榜单 / 剧场 / 收藏
4. **搜索**：进入搜索页，用遥控器字母键拼首拼；或在手机上打开电视屏幕提示的地址，用手机输入剧名
5. **播放**：选中剧集进入详情，OK 播放；播放中方向键唤出选集面板，可切换清晰度与倍速
6. **个性化**：设置里可调文字大小、全局清晰度与倍速、收藏分组、手机备份与恢复、自定义背景
7. **升级**：本分支不带自动更新，直接安装新版 APK 覆盖（签名一致时保留收藏与历史）

## 目录结构

```
kotlin-tv/            Android 原生工程（Kotlin + Media3）
  app/                应用模块：UI、播放、交互
  core/               数据层：内容仓库、快照、收藏索引、分季、检索
  gradle/             构建脚本与版本目录
server/               辅助服务（非必需，单 APK 可不部署）
scripts/              构建与发布脚本
.github/workflows/    CI：测试、lint、构建
```

## 构建

需要 JDK 17 与 Android SDK 36：

```sh
./kotlin-tv/gradlew -p kotlin-tv :core:test :app:assembleDebug
```

产物位于 `kotlin-tv/app/build/outputs/apk/debug/app-debug.apk`；版本号可用环境变量 `HONGGUOTV_VERSION_CODE` / `HONGGUOTV_VERSION_NAME` 覆盖。签名配置见 [kotlin-tv/README.md](kotlin-tv/README.md)，签名密钥不包含在仓库中。
