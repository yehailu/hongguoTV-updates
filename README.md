# hongguo TV

红果短剧的电视 / 手机 / 车机第三方客户端，开源（GPL-3.0）。单个安装包即可运行，无需自建服务、无需登录。

**[⬇ 下载最新安装包](https://cnb.cool/lzyr9010/hongguoTV-updates/-/releases/latest)**

## 能做什么

- **看剧**：首页推荐、排行榜、剧场分类、收藏，点开即播
- **搜索**：短剧与漫剧合并检索，支持遥控器首拼与手机输入
- **播放控制**：暂停 / 快进 / 快退、清晰度与倍速、自动连播、跳过片头片尾、定时关闭
- **弹幕**：平台官方弹幕，可开关并调节样式
- **收藏与追剧**：收藏分组、观看历史、断点续播
- **个性化**：文字大小、界面风格、自定义背景、手机备份与恢复
- **应用内更新**：发现新版本时应用内下载并升级

## 使用

1. 从 Release 页面下载对应安装包，安装到设备（首次安装需允许「安装未知来源应用」）。
2. 打开即用：联网即可播放，无需登录或配置服务器。
3. 电视遥控器：方向键移动焦点，OK 确认，返回键回上一级；播放中按 ↓ 选集、↑ 更多。
4. 手机 / 车机：点按画面调出菜单，包含选集、播放设置、返回选集等。
